相機用不了，或掃描一直失敗？把條碼數字（或商品型號）貼在這裡也可以。

運作原理：網頁本身沒辦法去操控 kakaku.com 頁面裡的搜尋框（不同網域的頁面彼此看不到對方的內容），所以這個工具改用 kakaku.com 自己的搜尋網址格式（search.kakaku.com/關鍵字/）直接帶你到結果頁，效果等同於「幫你打好字並按下搜尋」。

條碼掃描用的是瀏覽器內建的 Shape Detection API，目前只有 Chrome（Android／桌面）等 Chromium 系瀏覽器支援；若相機無法啟動，請改用下方手動輸入，或換 Chrome 開啟本頁。

另外，相機權限只有在網頁以 HTTPS 開啟時才會生效——若你是直接打開這個本機檔案，相機通常會被瀏覽器擋掉，需要把檔案放到有 HTTPS 的空間（例如 GitHub Pages、Netlify）再用手機開啟。

掃到條碼後會自動開新分頁，不用再按一次按鈕；但這個動作是在掃描迴圈裡觸發、不是你當下的一次點擊，有些瀏覽器的彈出視窗封鎖機制可能會擋下它。若被擋，畫面會出現一個手動開啟的連結當備援。

價格.com 的搜尋是用商品名稱／型號比對，不是每個 JAN 條碼都收錄在關鍵字索引裡；如果搜尋沒有結果，可以試試商品型號或名稱。
